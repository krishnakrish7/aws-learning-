## 🎯 About

This repository contains learning materials, code examples, and best practices for various AWS services. Whether you're a beginner or looking to deepen your AWS knowledge, you'll find valuable resources here.

## 🚀 Getting Started

1. **Create an AWS Account**: If you don't have one, sign up at [AWS Free Tier](https://aws.amazon.com/free/)
2. **Install AWS CLI**: Follow the [AWS CLI installation guide](https://docs.aws.amazon.com/cli/latest/userguide/install-cliv2.html)
3. **Configure AWS Credentials**: Run `aws configure` to set up your credentials
4. **Clone this repository**: `git clone https://github.com/krishnakrish7/aws-learning-.git`

## ☁️ AWS Services Covered

This repository includes learning materials for:

- **Compute**: EC2, Lambda, ECS, EKS
- **Storage**: S3, EBS, EFS, Glacier
- **Database**: RDS, DynamoDB, Aurora, ElastiCache
- **Networking**: VPC, Route 53, CloudFront, API Gateway
- **Security**: IAM, Secrets Manager, KMS, AWS Organizations
- **Infrastructure as Code**: CloudFormation, CDK, Terraform
- **Monitoring & Logging**: CloudWatch, CloudTrail, X-Ray
- **DevOps**: CodePipeline, CodeBuild, CodeDeploy

## 📋 Prerequisites

- Basic understanding of cloud computing concepts
- Familiarity with command line/terminal
- AWS Account (Free Tier is sufficient for most examples)
- AWS CLI installed and configured
- Basic programming knowledge (Python, JavaScript, or similar)

## 🛤️ Learning Path

### Beginner
1. Start with [Getting Started Guide](./getting-started/)
2. Learn about [IAM and Security](./security/iam/)
3. Explore [EC2 Basics](./compute/ec2/)
4. Try [S3 Storage](./storage/s3/)

### Intermediate
1. Deep dive into [VPC and Networking](./networking/vpc/)
2. Learn [RDS and Databases](./database/rds/)
3. Explore [Lambda and Serverless](./compute/lambda/)
4. Study [CloudFormation](./iac/cloudformation/)

### Advanced
1. Master [Infrastructure as Code](./iac/)
2. Implement [DevOps practices](./devops/)
