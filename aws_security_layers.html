AWS Shield

2
🔍 DETECTION — Find threats INSIDE
Monitors what's already in your environment. Finds threats and vulnerabilities.
👁️
GuardDuty
Detects active threats — compromised EC2, unusual API calls, crypto mining
Threat Intelligence • ML
🔎
Macie
Finds sensitive data (PII, credit cards, passports) stored in S3 buckets
S3 Only • PII Detection
🩺
Inspector
Scans EC2, ECR images & Lambda for software vulnerabilities (CVEs)
Vulnerability Scanning
▼
3
📋 AUDIT — Know what HAPPENED
Records every action and configuration change. Compliance and forensics.
📜
CloudTrail
Logs every API call — who did what, when, from where. Full audit trail.
API Logging • WHO did WHAT
📐
AWS Config
Tracks resource configuration over time. Compliance rules and drift detection.
Config History • WHAT changed
