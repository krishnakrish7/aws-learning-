# Getting Started with AWS

This guide will help you set up your AWS environment and get started with your learning journey.

## Prerequisites

- A valid email address
- A credit/debit card (for AWS account verification)
- Basic computer and internet knowledge

## Steps to Get Started

1. **[Create an AWS Account](./aws-account-setup.md)**
   - Sign up for AWS Free Tier
   - Verify your account
   - Set up billing alerts

2. **[Install and Configure AWS CLI](./aws-cli-setup.md)**
   - Install AWS CLI v2
   - Configure credentials
   - Test your setup

3. **[Learn IAM Basics](./iam-basics.md)**
   - Understand IAM concepts
   - Create IAM users
   - Set up MFA
   - Best practices for security

## Quick Start Checklist

- [ ] AWS account created
- [ ] Billing alerts configured
- [ ] AWS CLI installed
- [ ] AWS credentials configured
- [ ] IAM user created (instead of using root)
- [ ] MFA enabled on root and IAM user accounts
- [ ] First EC2 instance launched (optional)

## Important Security Tips

⚠️ **Never use root account for daily operations**
⚠️ **Always enable MFA on all accounts**
⚠️ **Never commit AWS credentials to version control**
⚠️ **Set up billing alerts to avoid unexpected charges**
